# Security and disclosure policy

This is a public evidence/disclosure repository, **not** a maintained software distribution. There is no implied list of supported software versions.

## Report sensitive information privately

Use the repository's **Security → Report a vulnerability** feature for private reports. Do **not** post active credentials, personal data, unpublished case evidence, or exploit details to public issues, discussions or pull requests.

If a report affects a third-party product or service, coordinate with the responsible vendor before publishing information that could put users at risk. The repository's public history is not a substitute for a private vendor disclosure channel.

## Evidence standards

Include the affected component/version, observed behavior, timestamps, reproduction constraints, and redacted provenance where appropriate. Separate directly supported facts from unverified hypotheses. Preserve the original evidence locally through a controlled chain of custody.

Submission does not imply acceptance, validation, a response deadline, or a promised remediation.
